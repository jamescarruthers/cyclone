# Cyclone (Vortex Software, 1985)

The ZX Spectrum game *Cyclone* by Costa Panayi: a full reverse engineering of the original, and a
3D remake in Rust + wgpu built from it.

| Path | What |
|---|---|
| [`re/`](re/README.md) | Reverse engineering: annotated disassembly, notes, extracted assets, tools |
| [`remake/`](remake/README.md) | The 3D remake (desktop and browser) |
| `original/` | The original tape and snapshot images |

The original game files and the data extracted from them remain the copyright of their owners.
