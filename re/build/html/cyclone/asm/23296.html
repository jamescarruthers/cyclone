5B00: Game start, per-level setup and main game loop
Copied here from F78A by F74E (it lives in the printer buffer). Entered from the main menu (E280) when "6" is pressed. Clears the screen, draws the HUD, updates the high score with the last game's score, zeroes the score and loads the 100 live game variables at $7500-$7563 from their initial values at $7564. 5B26 starts a level (also re-entered when a level is completed), 5B36 starts a life (also re-entered after a life is lost, from $92C5), and 5B3C is the free-running per-iteration loop (no HALT / interrupt sync: one iteration takes ~270000-390000 T-states, i.e. ~3.9-5.6 TV frames, ~9-13 iterations per second; all game timers count iterations).
