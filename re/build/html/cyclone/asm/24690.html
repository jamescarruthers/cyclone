6072: Put survivors on the map
Called at each level start (5B2F). For each of the 45 cells listed at 6018: if the map tile is a plain tile $58/$30/$10 (60AC) it is replaced by the survivor tile $89/$55/$2D (60AF) plus a random 0 or 1 (bit 0 of L from 8B74), so it becomes one of the two survivor variants $89/$8A, $55/$56, $2D/$2E (both are survivors to the winch, F515). Cells that still hold a survivor (not rescued) or a crate are left alone. OBSERVED: at the start of a game all 45 cells hold survivors.
6072 LD B,$2D 45 cells
6074 LD IX,$6018
6078 PUSH BC
6079 LD L,(IX+$00) HL = cell address
607C LD H,(IX+$01)
607F LD A,(HL) A = tile
6080 LD HL,$60AC Look up the three plain tiles
6083 LD DE,$60AF
6086 LD B,$03
6088 CP (HL)
6089 JR Z,$6091
608B INC DE
608C INC HL
608D DJNZ $6088
608F JR $60A3
6091 LD A,(DE) A = survivor tile
6092 EX AF,AF'
6093 CALL $8B74 Random variant (+0 or +1)
6096 EX AF,AF'
6097 BIT 0,L
6099 JR Z,$609C
609B INC A
609C LD L,(IX+$00)
609F LD H,(IX+$01)
60A2 LD (HL),A Store it
60A3 LD DE,$0002
60A6 ADD IX,DE
60A8 POP BC
60A9 DJNZ $6078
60AB RET
