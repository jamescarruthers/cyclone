6602: Add B points to the score
The score is the 7-character string at 661E ('.' = blank leading digit). Adds 1 to the last digit B times with decimal carry (B=0 adds 256), then prints it via 6F00. On exit B=$66 (left over from 6F00), which 83A5 relies on by accident.
Input
B Number of points to add
6602 LD HL,$6624 Last digit
6605 LD A,(HL)
6606 CP $2E A blank leading digit counts as '0'
6608 JR NZ,$660C
660A LD A,$30
660C INC A
660D CP $3A Carry?
660F JR NZ,$6616
6611 LD (HL),$30 Yes: digit := '0', move one digit left
6613 DEC HL
6614 JR $6605
6616 LD (HL),A
6617 DJNZ $6602
6619 JP $6F00 Print the score
