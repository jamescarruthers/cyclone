7500: LIVE GAME VARIABLES ($7500-$7563)
The 100-byte variable block. At game start 5B1B copies the initial values 7564 here (LDIR 100 bytes); after each lost life 92B3 copies 75C8 over it, skipping bytes whose reset value is $FF. Variable names below are those used in re/notes/core1.md (the glossary).
7500 DEFW $0000 POS_X: X: world X of view-window origin (16-bit, tiles); heli ground tile = X+11; +1 = east
7502 DEFW $0000 POS_Y: Y: world Y of view-window origin (16-bit, tiles); heli ground tile = Y+14; -1 = north
7504 DEFB $00 VIEW: View direction: 0 = view north, 1 = view south (world rotated 180 deg); toggled by N
7505 DEFB $00 CRASHED: Crash flag: 1 = helicopter destroyed (set by 8A7A at 8B5F)
7506 DEFB $00 HEADING: Heading 0-15 (22.5 deg units, 0=N 4=E 8=S 12=W); changes in steps of 2
7507 DEFB $00 HEADING_DISP: Displayed heading / sprite frame 0-15 (odd = mid-turn frame)
7508 DEFB $00 HEADING_NEXT: Heading at end of current turn (7506+-2 mod 16)
7509 DEFW $0000 TMP_GFX: Scratch pointer: tile-graphics/target pointer (7BB8, 7F21, 85D4) or column-list ptr (86AF)
750B DEFW $0000 TMP_ATTR: Scratch pointer into tile-attribute table FE00-FE7F (7BB8, 7F21, 85D4, 86AF)
750D DEFB $00 ALTITUDE: Altitude in pixels 0..60 ($3C); climb/descent 1..3 per loop
750E DEFW $0000 TMP_SPR: Scratch: shadow sprite source pointer (ED68+72*(frame+1)), +8 per cell
7510 DEFW $0000 TMP_LIST: Scratch: pointer into 7A9F column list (7BB8)
7512 DEFW $0000 TMP_MASK: Scratch: 7BB8 second mask pointer (word); 86AF/F4DA byte column counter 0..2
7514 DEFB $00 TOUCHDOWN: Touch-down flag: 1 = tried to descend below altitude 0 (8269); landing check in 8A7A
7515 DEFB $00 LANDED: Landed flag: 1 = on the ground (8AF7); UP clears it (take-off, 820D)
7516 DEFB $00 NO_FUEL: Out-of-fuel flag: 1 = fuel bar empty (82C1); forces descent, no climb/thrust
7517 DEFB $00 FUEL_TICK: Fuel tick: drain one fuel line every 49 loops (0..$30)
7518 DEFW $0000 FUEL_PTR: FUEL bar pointer (screen addr, column $1C); $47BC = empty
751A DEFB $00 CLIMB_RATE: Climb rate 0..3 px/loop (ramps while UP held)
751B DEFB $00 DESCENT_RATE: Descent rate 0..3 px/loop (ramps while DOWN held or no fuel); >=3 on contact = crash
751C DEFW $0000 TIME_PTR: TIME bar pointer (screen addr, column $1E); low byte $DE = time up
751E DEFW $0000 ALT_PTR: ALTIMETER bar pointer (screen addr, column $18)
7520 DEFB $00 Unused (never accessed: no static reference, no access in emulation)
7521 DEFB $00 TURN_TIMER: Turn timer: 3 at start of a 45-deg turn, completes at 1; 0 = idle
7522 DEFB $00 CONTROLS: Control bits: b0 forward, b1 down, b2 up, b3 right, b4 left
7523 DEFB $00 Unused (never accessed: no static reference, no access in emulation)
7524 DEFB $00 PLANE_COL: Aircraft view column (0..24 = buffer col+2, mirrored in south view)
7525 DEFB $00 PLANE_ROW: Aircraft view row (0..30 = buffer row+2, mirrored in south view)
7526 DEFB $00 UI_FLAGS: b0 M held, b1 map shown, b2 N held, b3 map closed (unused), b4 map needs drawing
7527 DEFB $00 SPEED: Speed/momentum 0..7: +1/loop thrusting, -1/loop coasting; moves 1 tile/loop while >0
7528 DEFB $00 TIME_TICK: Time tick: one TIME bar line lost every 255 loops (level 1), 15 fewer per level
7529 DEFW $0000 TMP_LIST2: Scratch: column-list pointer for heli body/rope occlusion (86AF, F4F8)
752B DEFW $0000 TMP_ATTR2: Scratch: attribute pointer for heli body cells (86AF, F4F1)
752D DEFB $00 SOUND_OFF: 1 = interrupt sound effects off (menu E282, death sequence 9278)
752E DEFB $00 ON_PAD: 1 = landed on a complete 3x3 helipad (tiles $83/$89): refuel, level check
752F DEFB $00 PLANE_DRAWN: 1 = an aircraft sprite was built this loop (only the first one)
7530 DEFB $00 PLANE_NEAR: Aircraft proximity: b0 X-window, b1 Y-window; 3 = BEWARE AIRCRAFT
7531 DEFB $00,$00 Unused (never accessed: no static reference, no access in emulation)
7533 DEFB $00 HELI_LEVEL: Heli altitude level for aircraft: alt/8+1 (1..7)
7534 DEFB $00 AIR_TICK: Free-running loop counter while airborne (bit 2 gates 7533 update)
7535 DEFB $00 WAVE_X: Sea-wave pattern column phase 0..8 (wraps to 4)
7536 DEFB $00 WAVE_Y: Sea-wave pattern row phase 0..6 (wraps to 3)
7537 DEFB $00 WAVE_TICK: Wave re-seed counter 0..2
7538 DEFW $0000 WAVE_PTR: Wave pattern source pointer $01xx (ROM bytes as random data)
753A DEFB $00 ROTOR_FRAME: Rotor animation frame: 0..1 flying, 0..3 landed / no fuel
753B DEFB $00 MOVE_DIR: Direction of travel (heading latched while thrusting); used when coasting
753C DEFW $0000 MAP_ROW_PTR: Map screen: pixel address of current island bitmap row (8D5D)
753E DEFW $0000 MAP_PTR: Map screen: running pixel pointer within the row (8D5D)
7540 DEFB $00 MAP_HX: Heli map column = X/32 clamped 0..22
7541 DEFB $00 MAP_HY: Heli map row = Y/32 clamped 0..21
7542 DEFB $00 MAP_BLINK: Map marker blink counter 0..6
7543 DEFW $0000 MAP_HATTR: Map: attribute address of heli marker
7545 DEFW $0000 MAP_HPIX: Map: pixel address of heli marker
7547 DEFW $0000 MAP_CATTR: Map: attribute address of cyclone marker
7549 DEFW $0000 MAP_CPIX: Map: pixel address of cyclone marker
754B DEFB $00 CYC_X: Cyclone map column 1..21 (start 2 or 20)
754C DEFB $00 CYC_Y: Cyclone map row 1..20 (start 2 or 19)
754D DEFB $00 OFF_MAP: Number of axes on which the heli is off the map grid (0..2)
754E DEFB $18 CYC_TICK: Cyclone move timer 0..24 (moves every 25 loops)
754F DEFB $11 CYC_LEG: Cyclone leg counter 0..8 (new random direction every 9 moves)
7550 DEFB $03 CYC_DIST: Distance heli-cyclone on map grid = max(abs dx, abs dy), capped 15
7551 DEFB $00 PICK_TILE: Replacement tile code written to the island map when a pickup starts
7552 DEFW $0000 ISLAND: Address of current island record (F230 table); $F294 = Base island
7554 DEFB $00 CRATES: Crates collected this level 0..5
7555 DEFB $00 WINCH: Winch countdown: 1..16 = object being winched up; 0 = idle
7556 DEFB $00 ROPE_STATE: Rope lowering state 0..2 (F39A)
7557 DEFW $0000 PICK_SPR: Pointer to sprite of hooked object: $F52F crate, $F548 survivor
7559 DEFB $00,$00 Unused (never accessed: no static reference, no access in emulation)
755B DEFB $00 SURV_ANIM1: Survivor animation counter 0..7 (frame swap at 4 and 8)
755C DEFB $00 SURV_ANIM2: Survivor animation counter 0..5 (frame swap at 3 and 6)
755D DEFB $00 ROTOR_SND: Rotor sound phase 0..3 (interrupt 83C2)
755E DEFB $00,$00,$00,$00,$00,$00 Unused (never accessed: no static reference, no access in emulation)
