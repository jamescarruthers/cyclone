762C: Copy the view buffer to the screen
Draws the 23x22-cell landscape view (screen columns 0-22, character rows 0-21) from the first 22 rows of the 23x29 tile buffer at $F74E. For each cell: attribute = byte $FE00+code; if code < $80 the 8 pixel bytes are copied from the tile set at $FA00+8*code, codes >= $80 are solid-colour tiles whose pixels are not touched.
Called from the main loop (5B86) when the map is not shown, and twice per step of the death sequence (9246/9284).
