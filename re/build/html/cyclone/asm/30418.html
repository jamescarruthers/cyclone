76D2: Build the view window from the island maps
Fills the 23x29 tile buffer at $F74E (row stride 23) with the part of the world map whose top-left world tile is (X,Y) = (7500, 7502). Everything outside an island is sea (code 0). The island table at $F230 has 20-byte records ($FF-terminated, 14 islands). Record bytes used here: +0 X high byte (sector), +1 Y high byte, +2/+3 X-low range in which the island is visible (= +6-22 .. +7+22), +4/+5 Y-low range (= +8-28 .. +9+28), +6/+7 X-low range of a fully visible window (map column 0 is world X = +6), +8/+9 the same for Y (map row 0 is world Y = +8), +10/+11 address of the island tile map (row stride 128 bytes).
The island found is stored in 7552. The clip flags in C are: bit 2 X < +6 (window overhangs the island's west edge), bit 3 X >= +7 (east edge), bit 4 Y < +8 (north edge), bit 5 Y >= +9 (south edge); C (0..40) indexes a table of 4-byte JP slots: 78CF for the north view (7504=0) or 7A37 for the south view, whose routines copy the visible rectangle (rotated 180 degrees for the south view).
Called every main-loop pass (5B3C) and by the death sequence (9257). World tile under the helicopter = (X+11, Y+14) = buffer cell (11,14) in both views.
