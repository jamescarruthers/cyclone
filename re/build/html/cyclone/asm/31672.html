7BB8: Draw the helicopter's shadow into the sprite tiles
The shadow sprite (3x3 cells, frame 7507, +8 mod 16 in south view; data at $EDB0+72*frame, cell order column-major bottom-up, first byte $FF = empty cell) is drawn into the graphics of the sprite tiles $5F-$7F (built by 7E10 at $FCF8-$FDFF, attributes $FE5F-$FE7F). Each shadow cell (column 10+c, row 15-k) is raised by its ground offset h (7A95), i.e. drawn into the sprite tile h rows higher, so the shadow lies on the terrain. The tile already displayed there (from 7A9F) decides how: < $17 flat ground: the cell is replaced by the shadow and its INK set to black; $17-$26 objects: the shadow is masked by mask tiles $23-$26 ($FB18-$FB37) and may continue into the tile below; $27-$2F: shadow ORed in, INK black; >= $30: not drawn (hidden). Offsets >= 8 (aircraft) draw at the base cell with attribute $68.
