7E10: Project the terrain and insert the sprite tiles
Turns the flat map window built by 76D2 into the pseudo-3D view, in place in the 23x29 buffer at $F74E. Rows are processed from the top (far) to the bottom (near) - a painter's algorithm: each cell of code c becomes a 'pillar': pillar tile k (k=0,1,2...) is byte (P+k)*256+c and is written k rows above the cell; $FE = transparent (leave what is there), $FF = end of pillar. P = $63 in north view and $6C in south view (operands 7E35/7E41 patched by 80F9). Nearer pillars overwrite farther ones.
Row 0 only gets its base tile. Rows 1-23 get full pillars. After row 15 the helicopter sprite tiles are inserted (7F21). Rows 24-28 (below the screen) only contribute the parts of tall pillars that reach the visible area: row 24+j draws only for codes >= $54, $80, $B2, $D0, $E4 (j=0..4), starting with pillar tile 3+j at row 21.
First the 9 raw codes of the 3x3 block under the helicopter are saved in 7A81.
