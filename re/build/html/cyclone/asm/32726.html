7FD6: Read the selected control device into the input bitmap 7522
Called once per main-loop iteration (5B8C). Reads the device chosen on the main menu (7FD5 = menu key - "2": 0 keyboard, 1 Sinclair Interface 2, 2 Kempston, 3 Protek/AGF cursor) and stores a 5-bit control word in 7522: bit 0 = forward thrust, bit 1 = descend, bit 2 = climb, bit 3 = turn right (clockwise), bit 4 = turn left. The cyclone code at 7378 may later OR random bits into 7522 (wind buffeting).
Input
(7FD5) control method 0-3
Output
(7522) control bits (0 fwd, 1 down, 2 up, 3 right, 4 left)
Keyboard (7FD5=0). Any key in a half-row counts, so the documented keys X / 1 / Q are really whole half-rows.
