80AA: Check the M (map) and N (view) keys, then process the flight controls
Called once per main-loop iteration (5BAC) except when the helicopter is landed away from the base with an empty tank. Reads half-row SPACE/SYM/M/N/B once. M toggles between the island view and the map; N toggles the view direction NORTH/SOUTH. Both are edge-triggered through latch bits in 7526 and each press beeps. Execution then falls through into the flight-control code at 8135.
Input
(7526) key latches / mode flags: bit0 M held, bit1 map mode, bit2 N held, bit3 map just left, bit4 map just entered
(7504) view direction 0=north 1=south
7526 bit 4 is consumed by the main loop (5B6F: redraw the map); bit 3 is set on leaving the map but nothing ever clears or tests it.
80AA LD HL,$7526 HL = mode flags
80AD LD A,$7F Read half-row SPACE/SYM/M/N/B
80AF IN A,($FE)
80B1 BIT 2,A M (bit 2) not pressed: clear the M latch
80B3 JR NZ,$80D8
80B5 BIT 0,(HL) M still held from the previous iteration: ignore
80B7 JR NZ,$80DA
80B9 PUSH AF Beep: BEEPER HL=$0361, DE=30 (about 489 Hz for 61 ms)
80BA PUSH HL
80BB LD HL,$0361
80BE LD DE,$001E
80C1 CALL $03B5
80C4 POP HL
80C5 POP AF
80C6 SET 0,(HL) Set the M latch
80C8 BIT 1,(HL) In map mode?
80CA JR Z,$80D2
80CC RES 1,(HL) Yes: leave map mode, set bit 3 ("map just left")
80CE SET 3,(HL)
80D0 JR $80DA
80D2 SET 1,(HL) No: enter map mode, set bit 4 ("map just entered": main loop draws the map)
80D4 SET 4,(HL)
80D6 JR $80DA
80D8 RES 0,(HL) M released: clear the latch
80DA BIT 3,A N (bit 3) not pressed: clear the N latch
80DC JR NZ,$8133
80DE BIT 2,(HL) N still held: ignore
80E0 JR NZ,$8135
80E2 SET 2,(HL) Set the N latch
80E4 LD A,$7F Blank the VIEW box (attribute $7F white on white) while beeping
80E6 CALL $8582
80E9 LD HL,$0300 Beep: BEEPER HL=$0300, DE=40 (about 548 Hz for 73 ms)
80EC LD DE,$0028
80EF CALL $03B5
80F2 LD A,($7504) Currently facing south? Then switch to north (80F9), else to south (8104)
80F5 CP $00
80F7 JR Z,$8104
