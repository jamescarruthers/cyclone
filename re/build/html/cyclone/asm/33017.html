80F9: Set the view direction to NORTH
Also called directly at game start / after a death (5B36), so it then falls through into the flight controls once. Sets 7504=0, prints NORTH (attr $38), and patches the tile-page high bytes used by the renderer (7B18, 7E35, 7E41, 7E6D, 7E93, 7EB9, 7EDF, 7F05) to the north set $63,$63,$63,$66,$67,$68,$69,$6A. Entry 8104 does the same for SOUTH: 7504=1, attr $78, text SOUTH (827F), pages $6C,$6C,$6C,$6F,$70,$71,$72,$73. Each tile code has one byte per height level in page base+0, +1, +2...; the two sets hold the tile stacks as seen from the north and from the south.
