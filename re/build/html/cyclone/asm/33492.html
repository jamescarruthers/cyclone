82D4: Raise the altimeter bar by one pixel
Moves the altimeter pointer 751E up one pixel line in column 24 and lights it ($FF). The bar runs from row 8 upwards (row 8 is lit at altitude 8; altitude 60 reaches row 1, line 4). Called by the climb code (8228) and by the landing code (8B16) when the altitude is rounded up.
Input
(751E) screen address of the top lit line of the A bar
82D4 PUSH AF
82D5 PUSH HL
82D6 LD HL,($751E) Up one pixel line
82D9 DEC H
82DA LD A,H
82DB CP $47 Crossing from the top line of row 8 into row 7 (screen third boundary)?
82DD JR Z,$82E7
82DF CP $3F Crossing a character row inside the top third?
82E1 JR NZ,$82F3
82E3 LD H,$47 Previous character row: H=$47, L=L-32
82E5 JR $82E9
82E7 LD H,$4F Third boundary: row 7 line 7 is $47F8
82E9 LD A,$E0
82EB ADD A,L
82EC LD L,A
82ED CP $F8
82EF JR NZ,$82F3
82F1 LD H,$47
82F3 LD (HL),$FF Light the line
82F5 LD ($751E),HL
82F8 POP HL
82F9 POP AF
82FA RET
