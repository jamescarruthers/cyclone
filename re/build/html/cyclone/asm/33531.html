82FB: Lower the altimeter bar by one pixel
Clears the top lit line of the altimeter bar and moves the pointer 751E down one line. Quirk: the test at 8307 uses $4F instead of $50, so below altitude 2 the pointer skips line 7 of row 8 and continues in row 9 (a stray line can then be drawn at $4838 when climbing back from altitude 0).
Input
(751E) screen address of the top lit line of the A bar
82FB PUSH AF
82FC LD HL,($751E) Erase the current top line
82FF LD (HL),$00
8301 INC H Down one pixel line
8302 LD A,H
8303 CP $48 Leaving the bottom of the top third?
8305 JR Z,$830F
8307 CP $4F Quirk: should be $50
8309 JR NZ,$831B
830B LD H,$48
830D JR $8311
830F LD H,$40 Next character row in the top third: H=$40, L=L+32
8311 LD A,$20
8313 ADD A,L
8314 LD L,A
8315 CP $18 Row 7 -> row 8: H=$48
8317 JR NZ,$831B
8319 LD H,$48
831B LD ($751E),HL
831E POP AF
831F RET
8320 NOP
