859A: Print a string in the main font
Prints C characters from HL at screen address DE (left to right, character cells), using the 8x8 font at 6028 (character code n at 6028+8n). Used throughout the game, the map (8EC1...) and the menu/info screens.
Input
HL string
DE screen address of the first cell
C character count
Output
HL address after the string
