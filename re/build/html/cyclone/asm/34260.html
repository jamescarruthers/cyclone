85D4: Let foreground slope tiles cover the helicopter
Called once per main-loop iteration (5B57), after the view has been built (7E10) and the helicopter drawn (86AF), before the view is copied to the screen (762C). Looks at the lower part of the helicopter's 3x11-cell window: view-buffer cells F86C + 23*i + j (i = 0-3 = window cells 7-10, j = 0-2 = window columns). Where such a cell holds a slope tile in front of the helicopter (codes $19-$1C) and the window cell's attribute has ink 0 (helicopter pixels were drawn there by 86AF), the window cell's bitmap is ANDed with a triangular mask (tile $23 for odd codes, $25 for even) and ORed with the slope edge (tile $17 blank for $19/$1A, $1B or $1C), its attribute set to $60 (bright green paper), and the cell's code replaced by the window tile code so the merged picture is displayed. Aircraft tiles $3C-$44 in those cells (8689, never seen executed) are ORed in instead.
