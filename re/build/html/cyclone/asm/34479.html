86AF: Draw the helicopter sprite into its view window
Called once per main-loop iteration (5B4E; also 9281 during the crash sequence). Draws the 24x24 sprite at 6950 (3 columns x 24 lines, column-major) into the helicopter window tiles $5F-$7F (3 columns of 11 cells = 88 pixel lines each, bitmaps at FCF8). The sprite's top line is at line 62-altitude of each 88-line column, so the helicopter rises one pixel per altitude unit above its shadow. Each cell-sized piece is drawn either solid (copied, rest of the cell cleared) when the cell's background code is below $1B and its attribute ink is non-zero (e.g. white wave dots on the sea), or ORed with a one-pixel 'cut' under every sprite pixel; the cell's ink is then set to 0 (black). Empty pieces leave the cell untouched.

(6950) helicopter sprite (built by 8CA0)
