8B74: Random number generator
Advances the 16-bit seed held in the ROM system variable SEED (5C76) and returns it in HL. The arithmetic is the classic Spectrum Lehmer step done without multiplication: new = ((254*(seed+1)) mod 65537) - 1 (verified for 3,206 seeds by emulation, including 0 and 65535). The sequence visits all 65,536 values (period 65536). Callers use L or H of the result.
Input
(5C76) seed
Output
HL new seed (also stored at 5C76)
A,D,E corrupted
8B74 LD DE,($5C76) DE = seed
8B78 LD H,E Form the 24-bit number A:H:L = seed*256 + $FD
8B79 LD L,$FD
8B7B LD A,D
8B7C OR A Subtract the seed twice (with borrow into A): A:HL = 254*seed + 253 = 254*(seed+1) - 1
8B7D SBC HL,DE
8B7F SBC A,$00
8B81 SBC HL,DE
8B83 SBC A,$00
8B85 LD E,A Reduce modulo 65537 (65536 = -1): HL = HL - A
8B86 LD D,$00
8B88 SBC HL,DE
8B8A JR NC,$8B8D On borrow add 65537 back (i.e. +1 in 16 bits)
8B8C INC HL
8B8D LD ($5C76),HL Store new seed
8B90 RET
