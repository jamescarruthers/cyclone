8B91: Animate sea waves in the view buffer
Called every main-loop iteration (5B45) and every step of the death sequence (925A), after 76D2 has rebuilt the view buffer (F74E, 23 columns x 22 rows of terrain codes) and before 7E10 converts codes to tile stacks. Puts random wave codes 0-3 into the empty (code 0 = open sea) cells of a sparse sheared lattice (7 rows x 4-5 columns, lattice vectors +5 cells across and +4 rows/+3 columns down). The lattice phase (7535 column 0..8, 7536 row 0..6) is shifted against the heading whenever the helicopter is moving, so the waves scroll with the motion; the random bytes are taken from ROM $0100+n, n re-randomised every 3rd call, so the wave pattern changes every 3 iterations.
Input
(7527) speed (0 = hovering: phase unchanged)
(7506) heading 0,2,..14 (0=N, clockwise)
(7504) view: 0 = north, 1 = south (180 degree rotated)
Cell written = F705 + 7535 + 23*B + 5*i + 95*j (j=0..6 rows, i=0..3 or 4), where B = 7536 (view north) or, view south, B = 7536+2 if that is < 7 else 7536-2; F705 = F74E - 73 (3 rows and 4 columns before the buffer start). If 7535 < 4 the first lattice column is skipped (+5). Columns per row: 5 if 7535 in 0,1,4,5,6; 4 if 7535 in 2,3,7,8 (the row stride is always 95). Only cells containing 0 are changed, to (ROM byte AND 3).
