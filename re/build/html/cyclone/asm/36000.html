8CA0: Build the helicopter sprite (with rotor) in 6950
Called every main-loop iteration (5B48) and for the first 3 steps of the death sequence. Copies the 72-byte (9 character, 3x3) helicopter graphic for sprite frame 7507 from E930+72*frame to the sprite buffer 6950-6997, then XORs one of the rotor overlays onto it. 86AF later draws 6950 into the view.
Input
(7507) displayed sprite heading frame 0-15 (moves one step at a time towards 7508)
(7504) view 0 north / 1 south
(7515) landed flag; (7516) fuel-empty flag
(753A) rotor animation frame
Frame used = 7507 (view north) or (7507+8) mod 16 (view south). For frames 10-15 the instruction at 8D02 becomes ADD A,A so the rotor overlay is shifted one pixel left (mirror-side frames). Rotor overlays (72 bytes each, XORed): flying: $7000+256*f, f = 753A cycling 0,1 (2-frame fast rotor); landed or out of fuel: $6700+256*f, f cycling 0,1,2,3 (4-frame slow rotor). (OBSERVED: 753A cycles 1,2,3,0 while landed, 0,1 in flight.)
8CA0 LD A,($7507) B = sprite frame
8CA3 LD B,A
8CA4 LD A,($7504) South view: frame = (frame+8) AND 15 (RES 4)
8CA7 CP $00
8CA9 JR Z,$8CB1
8CAB LD A,$08
8CAD ADD A,B
8CAE RES 4,A
8CB0 LD B,A
8CB1 LD HL,$8D02 Frames 0-9: NOP at 8D02; frames 10-15: ADD A,A ($87) at 8D02
8CB4 LD (HL),$00
8CB6 LD A,$09
8CB8 CP B
8CB9 JR NC,$8CBD
8CBB LD (HL),$87
8CBD LD HL,$E8E8 HL = E8E8 + 72*(frame+1) = E930 + 72*frame
8CC0 INC B
8CC1 LD DE,$0048
8CC4 ADD HL,DE
8CC5 DJNZ $8CC4
8CC7 LD DE,$6950 Copy the 72-byte graphic to 6950
8CCA LD BC,$0048
8CCD LDIR
8CCF LD DE,$7000 Rotor overlay page: $70 (flying)...
8CD2 LD A,($7515) ...or $67 if landed or out of fuel, with a 4-frame cycle
8CD5 CP $01
8CD7 JR Z,$8CE0
8CD9 LD A,($7516)
8CDC CP $00
8CDE JR Z,$8CEE
8CE0 LD DE,$6700
8CE3 LD A,($753A)
8CE6 INC A
8CE7 CP $04
8CE9 JR C,$8CF7
8CEB XOR A
8CEC JR $8CF7
8CEE LD A,($753A) Flying: 2-frame cycle
8CF1 INC A
8CF2 CP $02
8CF4 JR C,$8CF7
8CF6 XOR A
8CF7 LD ($753A),A
8CFA ADD A,D DE = (page+frame)*256
8CFB LD D,A
8CFC LD HL,$6950
8CFF LD B,$48
8D01 LD A,(DE) XOR 72 overlay bytes onto the sprite buffer
8D02 NOP Self-modified: NOP, or ADD A,A (shift overlay left) for frames 10-15
8D03 XOR (HL)
8D04 LD (HL),A
8D05 INC HL
8D06 INC DE
8D07 DJNZ $8D01
8D09 RET
