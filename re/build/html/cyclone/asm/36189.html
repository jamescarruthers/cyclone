8D5D: Map screen: draw the island shapes
Used when the map screen is entered (5B7B), after 8D0E. For each of the 14 island records at F230 (20 bytes each, list ends with $FF) it renders the island's heightmap at 1/4 scale: one map pixel per 4x4 world units, pixel set if the sampled height byte is >= $0F. Falls through into 8DE2 to print the names.
Input
F230 island table: +0A/+0B heightmap base, +0C/+0D map bitmap address (top-left), +0E width in pixels, +0F height in pixel rows
Heightmap format expected (same as the view builder 775E/7789): one byte per world unit, 128 bytes per world row, i.e. byte for (x,y) = base + 128*(y-y0) + (x-x0). The map samples pixel (px,py) at base + $102 + 4*px + $200*py, i.e. world offset (2+4*px, 2+4*py). Only the low byte is stepped (INC L x4), so a row must not cross a 256-byte page. Pixels are packed MSB first, 8 per screen byte; a final partial byte is padded with zero bits. 753C = start of current pixel row on screen, 753E = write pointer.
