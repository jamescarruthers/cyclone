8DE2: Print island names (4-pixel-wide font)
Prints the island names on the map in a half-width font, two characters per screen cell, black on bright white. Entry 8DE2 sets IX=F230, record stride 20 and the text pointer 6A4F; entry 8DEE is also used by the info screen (E446) with its own IX table (E68C), stride 3 (written to 8E0A) and text (E517).
Input
(IX+$10/$11) screen address one cell left of where the text starts; (IX+$12) attribute-file high byte ($58/$59/$5A) for that row
Text format (6A50-6AC9 for the map): ASCII bytes, with '?' ($3F) used as the space character. $FE = end of this name, move to the next record; $FD = append the shared suffix at 6AC2 ("?ISLAND", i.e. " ISLAND") which itself ends with $FC = return from suffix and move to the next record; $FF = end of all text. Glyphs: 8 bytes per character at 6908+8*code (only the left 4 pixels are used); even-numbered characters are copied into the next cell (and its attribute set to $78), odd-numbered characters are shifted right 4 pixels and ORed into the same cell. Map name order follows F230: BANANA, ORTE ROCKS, KOKOLA, LAGOON, PEAK, BASE, GILLIGANS, RED, SKEG, BONE, GIANTS GATEWAY, CLAW, LUKELAND ISLES, ENTERPRISE (ISLAND appended except for ORTE ROCKS, GIANTS GATEWAY, LUKELAND ISLES).
