8EE8: Draw a character C times
Copies the 8-byte character at IX to screen address DE, C times, advancing DE by HL each time (HL=1: next column, HL=$20: next character row; also $40 from the info screen). Used by 8E5C and the info screen (E4C2-E4D2).
Input
IX 8-byte character
DE screen address
HL step (in character cells; 32 = one row down)
C repeat count
Output
DE address after the last character
