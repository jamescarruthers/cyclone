8F12: Map screen: per-iteration update (blinking markers)
Called by the main loop instead of 762C/9034 while the map screen is shown (7526 bit 1). Wastes about 132,000 T-states (about 1.9 frames), then blinks the helicopter and cyclone markers with a 7-call cycle using counter 7542: calls 1-3 just update positions (9034), calls 4-6 remove the markers, call 7 resets the counter, updates positions and redraws the markers at their new cells (8F6A). OBSERVED: one map-mode iteration takes about 5.7 frames, so a blink cycle lasts about 40 frames.
