8F6A: Map screen: draw helicopter and cyclone markers
Saves the attribute and the 8 bitmap bytes of the character cell (column 7540, row 7541) and prints the helicopter marker there (main-font code $28 'H'-like glyph) with attribute $7A (bright, white paper, red ink); then does the same for the cyclone at (754B, 754C) with code $27 (swirl). Called on map entry (5B81) and by 8F12.

(754B),(754C) cyclone map cell

(7547) cyclone cell attribute address, (7549) its bitmap address, (9030) saved attribute, 9028-902F saved bitmap
