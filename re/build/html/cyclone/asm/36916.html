9034: Map positions, cyclone movement and wind-force/danger gauges
Called every main-loop iteration in the normal view (5B89) and on calls 1-3 and 7 of the map blink cycle. (1) Converts the helicopter's world position to a map cell. (2) Every 25 calls moves the cyclone one map cell in a random direction chosen from the current 'regime', picking a new regime every 9 moves or when the cyclone hits the map edge. (3) Sets 7550 = Chebyshev distance helicopter-cyclone (max 15) and draws the WIND FORCE bar and DANGER warning.
Input
(7500) helicopter X (16-bit world units), (7502) helicopter Y (Y grows southwards)
Output
(7540) map column = X/32 clamped to 0..22; (7541) map row = Y/32 clamped to 0..21
(754D) number of axes on which the helicopter is off the map (0-2)
(754B),(754C) cyclone map column 1..21 / row 1..20
(7550) distance to cyclone 0..15
Off-map test: if X/32 >= 256 (only possible for 'negative' X >= $2000) the column is 0; if 23 <= X/32 < 256 it is 22; rows likewise use 21. (The checks of H against $80 at 9054/9087 can never succeed, as H <= 7 after the shifts; dead code.)
Cyclone timing (OBSERVED, helicopter idling at base: 5.16 frames per main-loop iteration): one step every 25 iterations = about 129 frames (2.6 s); a regime lasts 9 steps (about 23 s) unless cut short at an edge.
