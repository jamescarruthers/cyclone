9300: Island tile store
The terrain of all 14 islands, one byte (tile ID) per map cell, stored as 150 rows of 128 bytes (stride 128). Each island is a rectangular block somewhere in this store, located by the island table at F230 (record bytes 10-11 = address of the block's top-left cell, block width = rec[3]-rec[6]+1, height = rec[5]-rec[8]+1); blocks are packed side by side and may share sea rows. The window builder 76D2 copies a 23x29 part of the active island into the window buffer F74E (row stride 128 -> 23), the renderer 7E10 turns every tile into a column of character codes via the tables at 6300+level*256+tile, and 762C draws it.
Tile IDs: 00 sea; 01-03 wave sparkles (only placed at run time by 8B91); 04-0E sea-level beach/rocks; 10-2C height 1; 30-54 height 2; 58-88 height 3; 8C-A4 height 4; B2-C1 height 5; D0-D8 height 6; E4-EB height 7 (class = count of 7AC2 entries <= tile, height = class/2). Odd classes are objects on that height: crates 0F/2F/57/8B (placed by 5EEC), survivors 2D-2E/55-56/89-8A (placed by 6072), houses and trees (A5-B1, C2-CF, D9-E3, EC-EF), aircraft F6-FE (written into the window only). See re/notes/data.md and re/assets/terrain/tiles.json.
Row 0 (9300-937F) is all zeros; 9246 also uses its first 72 bytes as a blank sprite to clear the helicopter buffer 6950.
