DE00: Aircraft sprite frames
16 frames of 72 bytes, one per direction (frame n = n*22.5 degrees clockwise from north/up; the code adds 8 modulo 16 in the south view). Each frame is a 24x24 image stored column-major: bytes 0-23 are the left 8-pixel column (top to bottom), 24-47 the middle column, 48-71 the right column; equivalently 9 characters in column order. 8995 copies the current frame (DDB8+72*(index+1)) to FBE0 (terrain chars 3C-44) and an AND AA/55 dithered copy to FB98 (chars 33-3B, the shadow); the plane is then drawn as window tiles F6-FE.
