E280: Main menu
Entered after initialisation (F74E), at game over ($92A6), from the info screen and when A+G abandons a game (5BE9). Silences the engine sound, beeps, waits for all keys to be released, draws the menu and highlights the selected controller. While waiting for a key it calls the crate shuffle (FE92) continuously. Keys: 1 = information screen (E3B4); 2 = keyboard, 3 = Interface 2, 4 = Kempston, 5 = Protek/AGF (cursor) joystick: stored as 0-3 in the control method $7FD5 (initially 0); 6 = start the game (5B00). Other keys are ignored.
