E3B4: Information screen
Menu option 1. Draws the HUD panel and labels every HUD element, the key controls and the map symbols, then waits for any key and returns to the menu. Also updates the high score (87BC).
E3B4 CALL $84D6 Clear the screen
E3B7 LD HL,$0400 Beep (pitch $0400, $70 cycles)
E3BA LD DE,$0070
E3BD CALL $03B5
E3C0 CALL $E3F8 Wait until no key is pressed
E3C3 JR NC,$E3C0
E3C5 CALL $84F4 Draw the HUD panel
E3C8 LD DE,$0009 Play area (23 x 22 cells): bright red ink on white paper
E3CB LD HL,$5800
E3CE LD C,$16
E3D0 LD B,$17
E3D2 LD (HL),$7A
E3D4 INC HL
E3D5 DJNZ $E3D2
E3D7 ADD HL,DE
E3D8 DEC C
E3D9 JR NZ,$E3D0
E3DB LD A,$03 $7530=3: aircraft collision warning lit
E3DD LD ($7530),A
E3E0 XOR A Speed $7527=0
E3E1 LD ($7527),A
E3E4 CALL $91B4 Draw compass/speedometer/warning
E3E7 CALL $6F00 Print the score
E3EA CALL $87BC Update and print the high score
E3ED CALL $E43A Print all the information texts
E3F0 CALL $E3F8 Wait for a key
E3F3 JR C,$E3F0
E3F5 JP $E280
