E3F8: Read the keyboard (ROM)
Uses ROM KEY-SCAN ($028E), K-TEST ($031E) and K-DECODE ($0333, L mode).
Output
A ASCII code of the key pressed (0 if none)
F Carry clear if a single valid key is pressed, set if none
