F39A: Winch: pick up crates and survivors
Called every main-loop iteration. $7A85 is the tile under the helicopter (centre of the 3x3 tiles saved by $7E10). If it is a crate (F511) or survivor (F515) tile, a rope is lowered: E = vertical gap in pixel lines between the helicopter and the object (from the view-buffer addresses; RET if negative or >255). If E>=17 the rope just dangles (12 lines, then 16 lines max) and nothing happens. If E<17 the rope takes two iterations to reach the object (winch state $7556: 0 -> 1 -> 2, the step is skipped if E>=13), then the object is hooked: the map cell is overwritten with the plain tile (F51B) so the object disappears from the world, and a crate increments $7554 and turns its HUD box red (attribute 2, boxes from the right). $7555 is then set to max(E,2)-1 and the object is reeled in by 1+$751B lines per iteration (faster while descending); when $7555 reaches 0 the points are scored: crate 250, survivor 50. When the helicopter moves off the object the rope is drawn retracted once (12 lines) and $7556 reset. While $7555<>0 the interrupt handler plays a winch beep.
