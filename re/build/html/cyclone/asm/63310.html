F74E: Initialisation
Jumped to from the loader entry FE98 after the tape has loaded. Copies the main-loop code to the printer buffer (F78A -> 5B00, 255 bytes) and the crate shuffle to 5EEC (F88A, 232 bytes), writes JP $5EEC at FE92, fills the IM2 vector table $FF00-$FFFF with $F3 (vector $F3F3 for any data bus value, incl. $FFFF/$0000 = $F3 $F3 from the ROM), sets I=$FF and IM 2 and enters the main menu. After this runs, the area from here to $F9FF is reused as the view buffer, so this code and the two source copies are overwritten during play.
