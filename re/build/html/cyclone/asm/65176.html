FE98: Program entry point (RANDOMIZE USR 65176)
The BASIC loader loads the screen ("Cyclone2"), this 512-byte block at $FE00 ("Cyclone4") and the main block at $5FDC-$FE91 ("Cyclone3", which overwrites $FE00-$FE91) with the ROM, then calls here. In the original loader block $FE00 decrypted $FE80-$FFFF (XOR with R) and $FE80 loaded the screen and the main block with its own LD-BYTES at $FE9F before falling into this code; that path is not used by this version.
